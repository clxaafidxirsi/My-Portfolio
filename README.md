## About this site

- One file: `index.html` (HTML, CSS and JavaScript together)
- Three colour palettes (Harbor, Night, Sun); the visitor's choice is remembered
- Works on phones, tablets and desktops
- Hosted for free on GitHub Pages

## Edit the site

1. Open `index.html`.
2. Change the text, project descriptions and links.
3. Commit and push. The site updates within a minute or two.

## Publish with GitHub Pages

1. Name the repository `clxaafidxirsi.github.io` and make it public.
2. Upload `index.html` to the `main` branch.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
